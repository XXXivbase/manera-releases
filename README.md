# MANERA

Рабочее место руководителя: калькуляторы метрик, KPI-монитор, команда, отчёты, таблицы и библиотека книг. Все данные хранятся только на вашем компьютере — без регистрации и сервера.

## Скачать

Последняя версия — в разделе [Releases](https://github.com/XXXivbase/manera-releases/releases/latest). Выберите файл для своей системы:

| Система | Файл |
| --- | --- |
| Windows 10 и 11 | `MANERA-<версия>-win-x64.exe` — установщик (рекомендуем) или `…-win-x64.zip` — без установки |
| macOS на Apple Silicon (M1–M4) | `MANERA-<версия>-mac-arm64.dmg` |
| macOS на Intel | `MANERA-<версия>-mac-x64.dmg` |
| Linux | `MANERA-<версия>-linux-x86_64.AppImage` |

## Установить

Приложение не подписано платным сертификатом разработчика, поэтому при первом запуске система предупредит об этом.

**Windows.** Если появилось окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае». Дальше — обычная установка.

**macOS.** Откройте `.dmg` и перетащите MANERA в «Программы». При первом запуске щёлкните по значку правой кнопкой → «Открыть» → «Открыть». Если macOS пишет, что приложение «повреждено», выполните в Терминале:

```
xattr -cr /Applications/MANERA.app
```

**Linux.** Сделайте файл исполняемым (`chmod +x MANERA-*.AppImage`) и запустите.

## Обновления

Установленное приложение само находит новые версии здесь. В Windows (установщик) и Linux при запуске показывается заставка: проверка, загрузка и установка обновления — затем MANERA открывается уже новой. На Mac и в zip-версии для Windows приложение сообщит о новой версии и предложит скачать её.

Данные сохраняются при обновлении. Резервную копию можно сделать в «Настройках».
